MusiAula Virtual

Videollamada + recursos + ejercicios + bitácora. Porque compartir pantalla ya tuvo demasiada fama para tan poquito esfuerzo.

Entrar al aula

Para probar con dos dispositivos: abre esta misma dirección en ambos y usa exactamente la misma sala.

Qué prueba esta versión

  • Videollamada integrada con Jitsi.
  • Panel lateral de clase con objetivo, recursos y actividad activa.
  • Sincronización básica entre participantes usando mensajes de datos de Jitsi.
  • Generador de escalas simples desde cualquier nota.
  • Metrónomo local, notas rápidas, bitácora y exportación JSON.
Importante: sin backend no hay base de datos real. Lo que se sincroniza ocurre mientras ambos están dentro de la sala. Lo guardado queda local en el navegador.
